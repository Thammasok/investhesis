Investhesis Guide
Setup โปรเจกต์ Supabase (local) Supabase (hosted) แก้ปัญหา

คู่มือ Setup Investhesis

วิธีติดตั้งโปรเจกต์ ตั้งค่า Supabase และรันระบบบนเครื่องของคุณ ตั้งแต่เครื่องใหม่จนถึงรัน test ผ่าน

1. Setup โปรเจกต์

ติดตั้ง Node, pnpm, Docker, ตั้งค่า .env และรัน web กับ API

2. Supabase บนเครื่อง

เปิด local stack, migration, allowlist สำหรับ sign-up และอ่าน email ทดสอบ

3. Supabase แบบ hosted

เตรียมโปรเจกต์บน Supabase Cloud: migration, hook, SMTP และ env

4. แก้ปัญหา

port ชน, Docker ไม่ขึ้น, sign-up ถูกปฏิเสธ และปัญหาที่เจอบ่อย

เริ่มเร็วใน 6 คำสั่ง

สำหรับคนที่มี Node 24+, pnpm และ Docker พร้อมอยู่แล้ว

pnpm install
cp apps/api/.env.example apps/api/.env
cp apps/web/.env.example apps/web/.env
pnpm db:start        # เปิด Supabase local (Docker)
pnpm db:reset        # ใส่ schema และ seed
pnpm dev             # web :5173 และ API :3000

เปิด http://localhost:5173 ได้เลย ค่าเริ่มต้นของ web คือโหมด mock (ไม่ต้อง sign-in) ถ้าอยากลอง sign-in จริง ดู ขั้นตอนใน Supabase (local)

แผนที่ของโปรเจกต์

ที่อยู่คืออะไร
apps/webReact + Vite (SPA), Tailwind v4, shadcn/ui, React Router
apps/apiFastify 5 + Zod, Drizzle บน pg, รัน TypeScript ด้วย Node โดยตรง
packages/domainคำศัพท์ กฎ และ Zod schema ที่ web กับ API ใช้ร่วมกัน
supabase/config, migration, seed, email template ของ Supabase CLI
e2e/Playwright (Chromium)
scripts/สคริปต์ db, ชุด test ระดับ script, ตัวสร้างรายงาน
docs/features/requirements, design, dev-plan และ test report ของแต่ละ feature
เอกสารนี้เขียนจากไฟล์จริงของ repo (package.json, supabase/README.md, .env.example) ถ้าคำสั่งใน repo เปลี่ยน ให้แก้ที่นี่ด้วย
